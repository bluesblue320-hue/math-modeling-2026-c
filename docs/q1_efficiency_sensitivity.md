# Q1 充放电效率解释敏感性分析

依据 `problem_spec.md` 第 7 节 A4，题目只写“充放电效率 90%”，未明确单程还是往返。
`model_spec.md` 第 3 节、H3 主模型解释为充电、放电各 0.90；本分析检验解释歧义的影响，
不改变主模型、不将主假设表述为题目唯一明确规定。输入仍为冻结的 A2 数据，时间遵循
`time_mapping_decision.md` 的 Mapping A；容量、功率、边界、目标与确定性 LP 结构相同。

Scenario A：η_ch=η_dis=0.90，往返效率为 0.81。
Scenario B：η_ch=η_dis=√0.90≈0.948683298，往返效率为 0.90。
两种场景的递推均为 E_t=E_(t−1)+η_ch P_ch Δt−P_dis Δt/η_dis，
其中充放电功率在微网母线侧计量，Δt=1/6 h。

B−A 费用为 **−1325.453047 元（−3.773322%）**。提高往返效率使全天购电量减少
1956.455517 kWh（约 3.29%），充电量减少 897.955656 kWh，放电量增加
1058.499861 kWh；节省比例提高 2.758370 个百分点。两种解释下储能都有明显节费效果，
定性结论一致，但成本差达到约 3.77%，定量报告应保留这一敏感性，不能视为可忽略的舍入差异。
这里比较的是确定性情景，不是统计显著性检验，也不能据此推断全年收益。

两组求解均为 Optimal，通过各自效率参数下的物理验证，同时充放电计数均为 0。
均全额消纳光伏且触及储电量上下限，主要运行特征一致。逐时段 grid/charge/discharge
最大绝对差分别为 3546.8412、1642.134462、3546.8412 kW；这些差异同时受到效率改变
和多重最优解选择影响，不能把单个时段轨迹差全归因于效率。

主论文及正式 `result1.xlsx` 仍采用 **Scenario A 的原 A3 最优方案**。
最优费用对应的轨迹可能不唯一。可选 representative optimum 仅以最小吞吐量选择代表解，
不保证唯一，也不保证更少切换；它不替代本次主方案或上述两场景第一阶段结果。
